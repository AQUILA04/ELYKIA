# Commerciaux

Ce menu sert à savoir **qui utilise un compte commercial**, et **entre quelles dates**. Le compte lui-même (par exemple COM001) ne change pas : c'est la personne qui l'utilise qui peut changer selon la période.

<!-- CAPTURE À INSÉRER : Menu Commerciaux ouvert, avec les entrées Comptes et Personnel. -->

## Ouvrir le menu

1. Dans le menu, cliquez sur **Commerciaux**.
2. Deux entrées s'affichent : **Comptes** et **Personnel**.

## Tenir l'annuaire du personnel

1. Cliquez sur **Personnel**.
2. Cliquez sur **Nouvelle personne**.
3. Saisissez le **nom**. Le téléphone, la date de naissance, la pièce d'identité et la photo de profil peuvent rester vides.
4. Cliquez sur **Enregistrer**.

Sans photo, la fiche affiche les initiales du nom.

Pour modifier une fiche, cliquez sur **Ouvrir**. La page rappelle les comptes que cette personne a tenus, avec les dates.

Une personne qui a déjà été affectée à un compte ne peut pas être retirée de l'annuaire : son historique reste visible.

## Affecter un compte

1. Cliquez sur **Comptes**.
2. Chaque ligne montre le compte, la personne qui l'utilise en ce moment, et la date de début. S'il n'y a personne, la ligne indique **Aucune affectation**.
3. Cliquez sur **Historique**.
4. Dans **Affecter une personne**, choisissez une personne de l'annuaire et une date de début.
5. Laissez la date de fin vide si la personne utilise le compte à partir de cette date, sans date de fin connue.
6. Cliquez sur **Affecter**.

## Changer de personne

Un compte n'est tenu que par une seule personne à la fois. Deux périodes ne peuvent pas se chevaucher, et une personne ne peut pas tenir deux comptes sur les mêmes dates.

1. Sur l'historique du compte, si une affectation est **En cours**, indiquez sa date de fin puis cliquez sur **Clôturer**.
2. La date de fin compte encore pour cette personne. La période suivante commence le lendemain.
3. Affectez ensuite la nouvelle personne.

La même personne peut revenir plus tard sur le même compte, dès que les dates ne se recouvrent pas.

## Corriger une période

1. Sur l'historique, cliquez sur **Corriger**.
2. Ajustez la personne ou les dates, puis cliquez sur **Enregistrer**.
3. **Retirer** enlève la période de l'historique. Les ventes et les encaissements déjà enregistrés sur le compte ne sont pas modifiés.
