# Dettes (commerciaux et magasinier)

Le menu **Dettes** regroupe les montants dus par les commerciaux (marchandise restante, écarts de caisse) et par le magasinier (écarts d’inventaire). Vous y consultez les totaux, le détail des articles ou des rubriques, et vous enregistrez les règlements.

## Accéder au module

1. Dans le menu latéral, cliquez sur **Dettes**.
2. Les cartes en haut affichent les dettes ouvertes, les avoirs (surplus de caisse), la position nette et le nombre de positions encore à constituer.
3. Utilisez les filtres (personne, type, statut, année, mois), puis **Filtrer**. Cliquez sur **Voir** pour ouvrir le détail.

## Dette marchandise (stock commercial)

Quand un mois est déjà terminé et qu’il reste des quantités chez un commercial :

1. Ouvrez **Stock Commercial** → **Stock mensuel**, puis activez **Historique** pour voir les mois passés.
2. Sur le panneau du mois concerné, cliquez sur **Créer la dette** (visible seulement s’il reste au moins une quantité).
3. Confirmez le montant proposé : les quantités passent de **Restant** à **Dette**.
4. Les cartes du mois affichent la **Valeur dette** (y compris après paiement) et le **Total dû** = vendu + dette + restant.
5. Depuis le détail de la dette, ou via **Voir la dette**, vous suivez le statut et les règlements.

## Écart de caisse

1. Sur le **Rapport journalier**, pour un **jour passé** d’un commercial, cliquez sur **Constituer l’écart de caisse** s’il y a un manquant ou un surplus.
2. Pour un **mois passé**, créez la position depuis le module Dettes (type manquant / surplus caisse).
3. Un surplus s’impute d’abord sur les manquants de caisse du même commercial. Vous pouvez ensuite l’utiliser lors d’un règlement sur une autre dette.

## Dette magasinier (inventaire)

1. Lors de la réconciliation d’un inventaire, sélectionnez les articles en écart négatif.
2. Cliquez sur **Marquer comme dette** et indiquez le magasinier responsable.
3. Le stock magasin est aligné sur le comptage physique et une dette apparaît dans le module Dettes.

## Marquer comme payé

1. Dans la liste Dettes, cochez une ou plusieurs dettes ouvertes.
2. Cliquez sur **Marquer comme payé(s)**.
3. Choisissez le mode : **Espèces**, **Imputer un surplus**, ou **Abandon** (motif obligatoire).
4. Indiquez le montant (paiement partiel possible) puis confirmez.

## Bilan annuel

Sur le **Rapport journalier**, pour un commercial sélectionné, le bilan annuel crédit affiche aussi :

- **Dette globale** : somme des dettes marchandise de l’année ;
- **Dette réglée** : total déjà réglé sur ces dettes.
