# Inscriptions clients (espace client)

Cette page explique comment valider les demandes d’inscription faites par les clients depuis l’application **Espace Client**.

---

## 1. Accéder à la liste

1. Dans le menu latéral, cliquez sur **Inscriptions clients**.
2. L’écran affiche les dossiers **en attente**, avec le nom, le téléphone, l’état de la pièce d’identité et le dépôt initial s’il a été déclaré.
3. Utilisez les filtres **Toutes**, **Avec dépôt** ou **Sans dépôt** pour prioriser les dossiers.
4. Cliquez sur **Actualiser** pour recharger la liste.

---

## 2. Examiner un dossier

1. Cliquez sur **Voir** sur la ligne du client.
2. Vérifiez la photo de profil, la photo de la pièce d’identité, l’adresse, le quartier et les informations de la pièce.
3. Si un dépôt initial a été déclaré, contrôlez le montant, le numéro Mobile Money et la référence du transfert.

---

## 3. Valider l’inscription

1. Choisissez le **commercial crédit** (obligatoire).
2. Choisissez éventuellement le **commercial tontine**.
3. Si un dépôt initial est en cours, laissez cochée l’option pour le valider et créditer le solde du compte.
4. Cliquez sur **Valider l’inscription**.
5. Le client peut alors utiliser pleinement l’espace client.

---

## 4. Refuser une inscription

1. Depuis le détail du dossier, cliquez sur **Refuser**.
2. Indiquez le motif du refus.
3. Le client verra un message l’invitant à contacter l’agence.

---

## 5. Côté client (Espace Client)

Un nouveau client qui saisit un numéro encore inconnu :

1. Reçoit un code SMS pour confirmer son téléphone.
2. Remplit sa fiche et prend sa photo de profil.
3. Crée son code PIN, puis se connecte.
4. Complète son dossier avec la photo de sa pièce d’identité.
5. Peut déclarer un **dépôt initial** (transfert Mobile Money puis saisie des détails) pour accélérer l’activation.
6. Attend la validation de l’agence avant d’accéder aux crédits, commandes et paiements.
