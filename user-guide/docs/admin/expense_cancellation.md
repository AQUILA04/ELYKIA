# Annulation d'une dépense

Cette page explique comment retirer une dépense enregistrée par erreur, tant qu'elle n'a pas encore été prise dans une remise de trésorerie.

---

## 1. Ouvrir la liste

1. Dans le menu latéral, cliquez sur **Dépenses**.
2. Le tableau **Dernières dépenses** liste les dépenses, avec la date, le type, le montant et les actions. Le lien **Voir tout** ouvre la liste complète : la corbeille et **Annuler la sélection** s'y trouvent aussi.

<!-- CAPTURE À INSÉRER : Tableau Dernières dépenses avec les cases à cocher et le bouton Annuler la sélection. -->

---

## 2. Annuler une seule dépense

1. Repérez la ligne.
2. Dans la colonne **Actions**, cliquez sur la corbeille.
3. Confirmez. La dépense disparaît de la liste et ne pourra plus être déduite d'une remise.

---

## 3. Annuler plusieurs dépenses

1. Cochez les lignes concernées. La case en tête de tableau coche les dépenses annulables de la page affichée.
2. Cliquez sur **Annuler la sélection**, en haut de l'écran.
3. Confirmez. Les dépenses cochées sont retirées ensemble.

Si l'une d'elles est déjà dans une remise, aucune n'est retirée. Reprenez la sélection sans cette ligne.

---

## 4. Dépense déjà dans une remise

Une dépense déjà associée à une remise, qu'elle soit en attente ou déjà reçue, ne peut pas être annulée.

- Sa case est inactive.
- La corbeille est inactive.
- Le badge **Comptabilisée** apparaît lorsque la remise a été reçue. L'infobulle indique que la suppression est impossible.
