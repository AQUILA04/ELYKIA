# Annuler les collectes d'un commercial

Cette page explique comment retirer toutes les collectes tontine d'un seul commercial pour une session annuelle, sans toucher aux collectes des autres commerciaux.

---

## 1. Ouvrir l'écran

1. Dans le menu latéral, cliquez sur **Tontines**, puis sur **Archives collectes**.
2. L'écran **Réinitialisation des collectes** s'ouvre.
3. Le bloc **Annuler les collectes d'un commercial** est sous les actions d'archivage de la session.

<!-- CAPTURE À INSÉRER : écran Archives collectes avec le bloc Annuler les collectes d'un commercial -->

---

## 2. Choisir le commercial et la session

1. Dans **Commercial**, choisissez le commercial dont les collectes doivent être retirées.
2. **Année** est déjà remplie avec la session en cours. Changez-la seulement si l'annulation concerne une autre session encore ouverte.
3. Cliquez sur **Aperçu**. Rien n'est encore annulé.

L'aperçu affiche :

- le nombre de collectes et leur montant ;
- le nombre de membres concernés, et combien d'entre eux gardent des collectes faites par d'autres commerciaux ;
- le montant de ces collectes conservées ;
- le nombre de lignes liées à une livraison.

---

## 3. Confirmer l'annulation

1. Cliquez sur **Annuler ces collectes**.
2. Lisez le message de confirmation, puis confirmez.

Après confirmation :

- les collectes de ce commercial disparaissent de la session ;
- les collectes des autres commerciaux, y compris sur les mêmes clients, restent ;
- les totaux de chaque membre concerné sont recalculés à partir de ce qui reste ;
- le rapport journalier de ce commercial est mis à jour sur les jours concernés ;
- une archive est conservée : fichiers PDF par quartier, et le détail des lignes, des membres et des jours.

Les livraisons de marchandises ne sont pas annulées. L'argent déjà remis en caisse n'est pas repris : le détail des jours sert à le rapprocher.

Si ce commercial n'a plus aucune collecte sur la session, l'annulation est refusée.
