# Espace client — Vue d’ensemble

Ce guide s’adresse aux **clients** qui utilisent l’application Espace Client ELYKIA (téléphone).

<!-- CAPTURE À INSÉRER : écran Accueil de l’espace client avec solde / crédits. -->

## Ce que vous pouvez faire

- Consulter vos crédits et votre prochain paiement sur **Accueil**
- Déclarer un paiement Mobile Money depuis **Achats**
- Suivre vos cotisations dans **Tontine**
- Passer une commande depuis **Commander**
- Compléter votre dossier dans **Mon dossier** (pièce d’identité, dépôt initial)
- Consulter vos alertes dans **Notifications** (cloche en haut à droite)

## Première connexion

1. Ouvrez l’application Espace Client. La première fois, l’écran affiche **Bienvenue**. Si vous êtes déjà venu sur cet appareil, il affiche **Bon retour !**.
2. Saisissez votre numéro de téléphone.
3. Si vous n’êtes pas encore client, lisez les conditions si vous le souhaitez, cochez **J’accepte les conditions d’utilisation**, puis **Continuer**. En les acceptant, vous vous engagez de bonne foi à respecter les contrats de crédit de vos achats et à payer les échéances prévues. Le code par SMS est envoyé seulement après cette acceptation. **Retour** vous ramène à la saisie du numéro.
4. Suivez les étapes (code reçu par SMS, création du code secret, fiche d’inscription si besoin).
5. Sur **Accueil**, si votre compte est encore en cours de validation, complétez **Mon dossier** pour accélérer l’activation : photo de la pièce d’identité, puis **dépôt initial** avec justificatif du transfert (capture ou reçu PDF).

Une fois votre compte validé par l’agence, l’Accueil affiche vos crédits et actions habituelles.
