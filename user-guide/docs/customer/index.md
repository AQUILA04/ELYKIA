# Espace client — Vue d’ensemble

Ce guide s’adresse aux **clients** qui utilisent l’application Espace Client ELYKIA (téléphone).

<!-- CAPTURE À INSÉRER : écran Accueil de l’espace client avec solde / crédits. -->

## Ce que vous pouvez faire

- Consulter vos crédits et votre prochain paiement sur **Accueil**
- Déclarer un paiement Mobile Money depuis **Achats**
- Suivre vos cotisations dans **Tontine**
- Passer une commande depuis **Commander**
- Compléter votre dossier dans **Mon dossier** (pièce d’identité, dépôt initial)
- Consulter vos alertes dans **Notifications** (cloche en haut à droite)

## Première connexion

1. Ouvrez l’application Espace Client.
2. Saisissez votre numéro de téléphone.
3. Suivez les étapes (code reçu par SMS, création du code secret, fiche d’inscription si besoin).
4. Sur **Accueil**, si votre compte est encore en cours de validation, complétez **Mon dossier** pour accélérer l’activation.

Une fois votre compte validé par l’agence, l’Accueil affiche vos crédits et actions habituelles.
