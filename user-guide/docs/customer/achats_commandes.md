# Achats et commandes — Espace Client

Cet écran vous permet de suivre vos crédits, commander des produits et déclarer vos paiements Mobile Money.

## Accueil

1. Ouvrez l’application Espace Client.
2. Sur **Accueil**, consultez votre crédit en cours et les raccourcis **Payer**, **Commander**, **Achats**, **Tontine**.
3. Appuyez sur **Mes adhésions et plafonds** pour voir le solde et le plafond de chaque adhésion active.

## Mes achats

1. Appuyez sur l’onglet **Achats**.
2. Filtrez par **Tous**, **En cours**, **Terminés** ou **Initiés**.
3. Appuyez sur une ligne pour ouvrir le détail.

### Détail d’un achat

1. Consultez le montant, le payé et le restant. Un crédit actif s’affiche avec le statut **EN COURS**.
2. Appuyez sur **Payer une mise** (bouton flottant) pour déclarer un paiement Mobile Money.
3. Appuyez sur **Voir le suivi des mises** pour l’historique des échéances.
4. Sur le suivi, vous pouvez aussi appuyer sur **Payer une mise** même si aucune échéance n’est encore listée.

### Déclarer un paiement

1. Lisez le numéro indiqué pour envoyer votre transfert.
2. Ajoutez le **justificatif du transfert** : une capture du message de confirmation, ou le reçu PDF de l’opération. Pour une capture, si une fenêtre **Autorisation requise** s’affiche, appuyez sur **Autoriser**. Si vous aviez déjà refusé, appuyez sur **Ouvrir les paramètres**, activez l’appareil photo ou les photos pour Elykia, puis recommencez.
3. Attendez éventuellement le message « Lecture du justificatif… » : la **référence du transfert** peut se remplir automatiquement. Vérifiez-la et modifiez-la si besoin.
4. Renseignez le **numéro d’envoi** et le **montant**.
5. Appuyez sur **Soumettre le paiement** en bas de l’écran.

Le justificatif est obligatoire pour envoyer la déclaration.

### Payer depuis l’application

Lorsque l’écran propose **Payer depuis l’application**, ou uniquement le choix du réseau :

1. Si deux choix sont proposés, **Je paie moi-même** sert à faire le transfert de votre côté et à joindre la preuve. **Payer depuis l’application** demande le montant sur votre mobile money, avec des frais en plus.
2. Choisissez **Mixx by Yas** ou **Flooz**.
3. Lisez les **frais de retrait**, les **frais** du réseau (en pourcentage) et le **total prélevé**.
4. Saisissez votre numéro, puis appuyez sur **Payer**.
5. Confirmez la demande sur votre téléphone. Le paiement est enregistré lorsque la confirmation aboutit.

Si aucun frais de retrait n’est prévu pour votre mise, le paiement direct n’est pas proposé pour ce réseau.

## Commander

1. Appuyez sur l’onglet **Commander**.
2. Chaque produit affiche sa photo lorsqu’elle est disponible, avec son nom et son prix.
3. Recherchez un produit ou filtrez par catégorie.
4. Appuyez sur **Ajouter**, puis ouvrez le panier.
5. Sur **Mon panier**, ajustez les quantités, consultez le **résumé de la commande**, puis appuyez sur **Passer la commande**. Si plusieurs adhésions sont actives, choisissez le type de crédit (**Personnel**, **Professionnel** ou **Événement**) avant de valider. Le plafond affiché est celui de ce type.

## Mes adhésions

1. Depuis l'accueil, ouvrez **Mes adhésions et plafonds**. Sur ordinateur, le menu **Adhésions** mène au même écran.
2. Chaque carte indique le type, le statut, le solde et le plafond de crédit.
   * **Personnel** : plafond 35 000 FCFA.
   * **Business** et **Événement** : plafond égal à 6 fois le solde de ce type. L'adhésion business ouvre aussi le crédit personnel et le crédit événement.
3. Pour souscrire ou ajouter de l'argent au solde, envoyez le montant par Mobile Money, puis remplissez **Déclarer un dépôt Mobile Money** : opération, type, numéro d'envoi et référence du transfert. Pour un ajout au solde, saisissez aussi le montant.
4. Appuyez sur **Envoyer la déclaration**. L'agence vérifie le transfert avant de l'appliquer.

## Sur ordinateur

1. Utilisez le menu à gauche : **Accueil**, **Achats**, **Commander**, **Adhésions**, **Panier**, **Profil**.
2. Sur **Accueil**, les montants de crédit s’affichent en cartes en haut de page, avec les actions rapides à droite. **Adhésions** ouvre vos soldes et plafonds.
3. Sur **Achats**, la liste apparaît en tableau : cliquez une ligne pour le détail. Le panneau de droite propose **Payer une mise** et **Voir le suivi des mises**.
4. Sur **Commander**, les catégories sont à gauche, les produits au centre (avec leur photo lorsqu’elle est disponible), et un mini-panier à droite. Ouvrez **Voir le panier** pour finaliser.
