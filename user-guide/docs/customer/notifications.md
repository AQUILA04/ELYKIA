# Notifications (espace client)

Les notifications vous informent lorsque l’agence traite votre dossier ou vos paiements.

<!-- CAPTURE À INSÉRER : cloche Accueil avec badge + liste Notifications. -->

## Ouvrir les notifications

1. Sur **Accueil** (ou **Profil**), touchez la **cloche** en haut à droite.
2. Un chiffre rouge indique le nombre de messages non lus.
3. La liste affiche les messages les plus récents en premier.

Sur ordinateur, cliquez sur **Notifications** dans le menu à gauche ; le nombre de messages non lus s’affiche à côté.

## Types de messages

Vous pouvez recevoir notamment :

- **Compte activé** — votre inscription a été validée
- **Inscription non validée** — votre dossier n’a pas pu être accepté
- **Paiement validé** ou **refusé** — suite à une déclaration Mobile Money sur un crédit
- **Cotisation validée** ou **refusée** — suite à une déclaration tontine
- **Commande** — changement de statut de votre commande

## Lire un message

1. Touchez un message : il est marqué comme lu.
2. L’application ouvre l’écran concerné (Accueil, Achats, Tontine, etc.).
3. Pour tout marquer comme lu d’un coup, touchez **Tout lu** en haut à droite.

## Astuce

Tirez la liste vers le bas pour actualiser. Les nouveaux messages apparaissent aussi après un retour sur **Accueil**.
