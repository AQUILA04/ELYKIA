# Connexion — Espace Client

Cet écran vous permet d’ouvrir votre Espace Client avec votre numéro de téléphone et votre code PIN.

## Où ouvrir l’Espace Client

Vous pouvez utiliser l’Espace Client de trois façons, avec le même numéro de téléphone et le même code PIN :

- **Sur votre téléphone** : ouvrez l’application **Elykia — Espace Client**.
- **Dans un navigateur** (téléphone ou ordinateur) : allez sur **https://clients.amenouveve-yaveh.com**.
- **Depuis le site Aménouvévé-Yaveh** :
    - cliquez sur **Espace client** en haut de la page (ou **Se connecter à l’espace client** dans le menu sur téléphone et en bas de la page) pour arriver sur l’écran de connexion ;
    - cliquez sur **Commander** ou **Commander maintenant** pour ouvrir directement le **catalogue**. Si vous n’êtes pas encore connecté, l’écran de connexion s’affiche d’abord, puis le catalogue s’ouvre dès que vous êtes connecté.

## Se connecter

1. Ouvrez l’application **Elykia — Espace Client** ou l’adresse **https://clients.amenouveve-yaveh.com** dans votre navigateur.
2. Sur l’écran avec **AMENOUVEVE-YAVEH**, **Elykia** et **Espace Client**, saisissez votre **numéro de téléphone**.
3. Appuyez sur **Continuer**.
4. Saisissez votre **code PIN**, puis appuyez sur **Se connecter**.
5. Votre **tableau de bord** s’affiche. Si vous étiez arrivé par un lien vers une page précise (par exemple le catalogue depuis le bouton **Commander** du site), c’est cette page qui s’ouvre.

## Première activation

Si votre compte n’a pas encore de code PIN :

1. Saisissez votre numéro de téléphone, puis **Continuer**.
2. Entrez le **code reçu par SMS**, puis appuyez sur **Vérifier**.
3. Choisissez un **nouveau code PIN**, confirmez-le, puis appuyez sur **Activer mon compte**.

## Créer un compte

Si votre numéro n’est pas encore connu et que l’inscription est ouverte :

1. Saisissez votre numéro, puis **Continuer**.
2. Validez le code SMS.
3. Renseignez vos informations (photo, identité, adresse) et appuyez sur **Continuer**.
4. Créez votre code PIN, puis appuyez sur **Créer mon compte**.

## Besoin d’aide

En bas de l’écran de connexion, le message **Première connexion ? Contactez votre agence** vous indique à qui vous adresser si votre numéro n’est pas reconnu.

## Sur ordinateur

1. Ouvrez **https://clients.amenouveve-yaveh.com** dans votre navigateur (fenêtre large).
2. À gauche, un panneau présente **AMENOUVEVE-YAVEH**, **Elykia** et les avantages de l’espace.
3. À droite, utilisez le formulaire de connexion comme sur mobile (téléphone, puis PIN ou code SMS).
4. Pour une inscription, les champs d’identité s’affichent sur deux colonnes ; choisissez votre photo avec **Choisir une photo**.
