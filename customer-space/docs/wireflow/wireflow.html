Légende & Notes de conception
Statuts métier

INITIÉ Créé par le client, en attente de validation agence.

VALIDÉ Confirmé par un agent depuis le frontend back-office.

LIVRÉ Commande livrée — le crédit commence à cette date.

Navigation principale

Bottom navigation à 5 onglets : Home (tableau de bord), Achats (historique), Commandes (catalogue + suivi), Paiements (timeline recouvrements), Profil. Onglet actif en or.

Paiement Mobile Money v1

Flux manuel en 3 champs : numéro d'envoi, montant envoyé, référence du transfert. Le paiement est créé à l'état INITIÉ. La validation est faite par un agent depuis le frontend agence. Le client reçoit une notification push à la validation.

Cycle de vie d'une commande

Le client compose son panier depuis le catalogue, soumet la commande (état INITIÉ). L'agence valide puis livre. Le crédit ne démarre qu'à la livraison. Le stepper 3 étapes est visible sur l'écran de confirmation.

Timeline des recouvrements

Chaque mise est représentée sur une timeline verticale. Les mises passées sont vertes (VALIDÉ), la mise en attente est orange (INITIÉ), les futures sont grises. Le CTA sticky permet de payer la prochaine mise directement.

Code base unique

L'application cible un code base unique pour Android et Web. Les écrans mobiles (390px) sont prioritaires. Le design system utilise des variables CSS pour faciliter le thème et la maintenance.
